**Methodology**
- `grants_awarded_usd`: Σ awarded FAA grant totals (award date present)
- `rank_score`: Σ weight × minmax_in_set-scaled criterion; criteria: grants_awarded_usd (higher_better, w=1.0)

**Caveats and limitations**
- Awarded grant dollars at award date; not spending or project completion.
- Federal fiscal year (Oct–Sep).
- Scores are relative to the airports in this set; adding/removing airports changes them.
- Exploratory SQL: definitions are not catalog metrics; verify before relying on it.
- Awarded grant dollars are totals with an award date. They are not outlays, spending, or project completion.
- The window is the federal fiscal year, October through September, for FY2021–2025. Grant coverage in the catalog is FY2021 through FY2025.
- MKL is in the hub class N group and is omitted from the rank because the grants metric is missing. Missing is not the same as a measured zero.
- Nonprimary commercial-service airports are outside hub class N and are not ranked. Exploratory counts: hub class None and service level CS is 169 (exploratory query); hub class - and service level CS is 6 (exploratory query).
- Award totals in the scored set are all different, so this order has no ties. Relative scores use minmax scaling inside this set and change if airports are added or removed. This run is not op=screen, so there are no screening-scenario flags.
- Unmet demand, terminal capacity, fares, and profitability are not measured by these data. A higher grant total is not a finding about investment merit.
