## 1. Chat UI

The current wire format is the UI message stream: SSE, header `x-vercel-ai-ui-message-stream: v1`, parts for text, tool input/output, `source-url`, and `data-*` ([stream protocol](https://ai-sdk.dev/docs/ai-sdk-ui/stream-protocol)). That page links a FastAPI example at [`vercel/ai/examples/next-fastapi`](https://github.com/vercel/ai/tree/main/examples/next-fastapi). The older template [`vercel-labs/ai-sdk-preview-python-streaming`](https://github.com/vercel-labs/ai-sdk-preview-python-streaming) (last push 2026-04-19, no LICENSE file) still speaks the old `x-vercel-ai-data-stream` / `9:{...}` protocol and routes through the Vercel AI Gateway OIDC token. Do not copy it.

**Local demo:** Pipecat + SmallWebRTC + faster-whisper + Piper (English). Function handlers call the existing tool functions and return the grounding validator’s `{F#}` text, which the server renders before it is spoken. Text and voice then share tools, findings, and the validator. LiveKit is the better product voice stack once a demo needs real turn-taking; it is more processes (media server, TURN, Cloud or self-host). Gemini Live is the Hebrew shortcut and a second brain: tool results must already be grounded, or the voice model will speak numbers we cannot trace. It is not zero-cost once you leave the free tier, and the free tier trains on the audio.

## 3. Web research

Keep web hits out of the findings table. Record `external_web`: `url`, `retrieved_at`, `query`, `title`, `snippet` (quoted, length-capped), `extractor`. The validator already refuses numerals that are not `{F#}`. Web numerals need their own server-rendered token, `{W#}`, resolved from that row. `compose_answer` may show the row in the sources panel. It must not copy the snippet into a finding.

**Zero-cost path**

1. Search: [SearXNG](https://github.com/searxng/searxng) (AGPL-3.0, push 2026-11-02, no GitHub releases or tags). Your process, no API key. Public instances are not a dependency. Laptop fallback: [`ddgs`](https://github.com/deedy5/ddgs) MIT, v9.16.1 2026-10-23. The PyPI text says educational use; engines get disabled between releases (Google and Yandex have been). No SLA.
2. Extract: [trafilatura](https://github.com/adbar/trafilatura) Apache-2.0 since v1.8.0 (earlier was GPLv3+), v2.3.1 2026-10-06. Local. Quote the extracted passage; do not let the model invent a quotation.
3. JS-only pages: [Jina Reader](https://github.com/jina-ai/reader) Apache-2.0, `https://r.jina.ai/<url>`, last push 2026-05-22, README says free. Sending the URL to Jina is a data leak. Rate limits and the “$50 per 1B tokens” figure were not on a page I opened. UNVERIFIED.

**Not in the zero-cost design**

- [Tavily](https://docs.tavily.com/documentation/api-credits): 1,000 credits/month, no card. Basic search is 1 credit, advanced is 2. Pay-as-you-go $0.008/credit. Docs page fetched this session.
- [Exa](https://exa.ai/docs/admin/pricing): $10 credits each month, no card, plus a one-time $10 onboarding bonus. Lite search $4/1k, auto/fast $7/1k (docs updated 2026-11-02).
- Brave: [dashboard pricing](https://api-dashboard.search.brave.com/documentation/pricing) shows Search at $5/1,000 with $5 monthly credit (card). The [marketing page](https://brave.com/search/api/) also shows a Free AI plan at 2,000 queries/month. Those pages disagree. Not a clean $0 dependency.
- Gemini grounding, from the pricing page opened above: Gemini 3 and newer get 5,000 search requests/month shared, then **$14 per 1,000**, with a 1,500 request/day cap. One prompt can issue several billed queries. Free-tier Live says grounding is “Supported,” not that it is free, and free-tier data is used to improve Google products. The model also writes the answer, which fights the validator.

**Primary aviation pages, fetched by us, stored as `external_web`:** FAA airport and NASR data (`https://www.faa.gov/air_traffic/flight_info/aeronav/aero_data/`, `https://www.faa.gov/airports`), BTS TranStats and the open-data portal (`https://www.transtats.bts.gov/`, `https://data.bts.gov/`). Access methods were not re-fetched this session. SWIM is a separate credentialed feed. Do not treat a search snippet of an FAA page as a finding.
